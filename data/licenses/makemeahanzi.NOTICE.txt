upstream graphics.txt. It contains 9574 character records. The separate
dictionary.txt dataset has not been included.

This project's preview-strokes workflow normalizes and rasterizes the source
outlines, then creates stroke-edited candidates. It does not modify the bundled
source file. Distributed derived graphical files carry dated modification
notices and are provided under Arphic-1999, without warranty. Preview folders
include ARPHICPL.txt and the source lock; each candidate has an auditable
before/after layer archive. Preserve these notices and the license when sharing
the preview. The independently written Python software is separate from these
licensed graphical assets.

This resource is registered for human calibration only (production_allowed=false).
No candidate is automatically an illegal Chinese glyph or an approved training
label. This notice does not constitute clearance for a production deployment.
